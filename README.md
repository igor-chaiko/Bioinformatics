# Bioinformatics
Действующее вещество
Левотироксин (Levothyroxine, L-thyroxine, T4) — это искусственно созданный аналог тироксина, гормона щитовидной железы. В лекарственных препаратах, как правило, применяется его форма — левотироксин натрия.

Молекулярный механизм действия
Левотироксин (T4) преимущественно выступает в роли прогормона, который в организме частично преобразуется в трийодтиронин (T3). Трийодтиронин связывается с ядерными тиреоидными рецепторами (TRα/TRβ) и влияет на экспрессию различных генов, регулируя метаболизм, процессы роста и развитие тканей. Такой эффект относится к геномному (транскрипционному) механизму действия тиреоидных гормонов.

Область применения
Левотироксин используют для заместительной терапии при недостаточной функции щитовидной железы (гипотиреозе). В некоторых случаях по назначению врача препарат применяется также для подавления продукции тиреотропного гормона (TSH), например, после лечения некоторых заболеваний щитовидной железы.
